
# Hospital Appointment Booking Application

## Day 3 – Set 3
### Agile and Scrum – Foundations and Backlog Workshop

## Project Overview

The Hospital Appointment Booking Application is a mobile application designed to help patients book, reschedule and cancel doctor appointments. It also provides reminder notifications and supports doctor schedule management.

## Project Epics

1. Appointment Booking
2. Appointment Rescheduling and Cancellation
3. Reminder Notifications
4. Doctor Schedule Management

## User Stories

The product backlog contains 14 user stories distributed across four epics.

## Agile and Scrum Activities

- Product vision statement preparation
- Stakeholder identification and Scrum role mapping
- Epic and user story creation
- INVEST principle evaluation
- Given/When/Then acceptance criteria
- Business value versus effort prioritisation
- Planning Poker estimation
- Story points versus hours comparison
- Definition of Ready (DoR)
- Definition of Done (DoD)
