# Day 3 – Set 2: Insurance Claims Portal

## Project Overview

The Insurance Claims Portal is a self-service application designed to help customers manage their insurance claims online.

Customers can register claims, upload supporting documents, track claim progress and receive settlement notifications.

This project was prepared as part of the Day 3 Agile and Scrum – Foundations and Backlog Workshop.

## Objectives

- Understand Agile and Waterfall methodologies.
- Define product vision and business requirements.
- Create epics and user stories.
- Apply INVEST principles and vertical story splitting.
- Write acceptance criteria using Given / When / Then.
- Estimate user stories using Planning Poker.
- Configure a Jira Scrum project and workflow.

## Story Estimation

The project uses Planning Poker with the following Fibonacci-style estimation values:

`1, 2, 3, 5, 8, 13`

- Total User Stories: 14
- Total Story Points: 48
- Estimation Method: Planning Poker

## Scrum Workflow

The Jira project uses the following workflow states:

1. To Do
2. In Progress
3. In Review
4. Done

## Definition of Done

The Definition of Done includes:
- Requirements implementation
- Acceptance criteria verification
- Code review
- Unit and integration testing
- Validation and security checks
- Documentation updates
- Jira status updates
