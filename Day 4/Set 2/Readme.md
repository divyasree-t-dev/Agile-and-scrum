# Day 4 – Set 2: Airline Web Check-in – Blocked Dependency

## Project Overview

This assignment demonstrates Agile and Scrum practices for an airline web check-in project where the payment gateway sandbox becomes unavailable during an active sprint.

## Business Scenario

The airline web check-in development team is working on a seat-upgrade story when the required payment gateway sandbox becomes unavailable.

The team must manage the external dependency while continuing work on other independent sprint stories.

## Deliverables

### 1. Sprint Plan
File: `Sprint_Plan.docx`

Includes:
- Team capacity calculation.
- Sprint commitment.
- Sprint Goal.
- Selected user stories.
- Definition of Ready checks.
- Blocked story analysis.

### 2. Impediment Log
File: `Impediment_Log.docx`

Includes:
- Impediment description.
- Business and technical impact.
- Ownership.
- Escalation path.
- Expected resolution.
- Scrum Master actions.
- Preventive measures.

### 3. Backlog Refinement
File: `Backlog_Refinement.docx`

Includes:
- Next sprint's top five stories.
- Refinement discussion.
- Splitting an oversized story.
- Revised story estimates.
- Dependency identification.

### 4. Sprint Review Agenda
File: `Sprint_Review_Agenda.docx`

Includes:
- Sprint Review meeting details.
- Meeting agenda.
- Demonstration script.
- Acceptance criteria.
- Stakeholder feedback questions.
- Review outcomes.

### 5. Asynchronous Stand-up
File: `Async_Standup.md`

Includes:
- Written updates from six team members.
- Two different time zones.
- Identified impediments.
- Scrum Master's follow-up actions.
- Comparison between asynchronous and live stand-ups.

## Topics Covered

- Agile and Scrum.
- Sprint Planning.
- Team Capacity Calculation.
- Story Selection and Estimation.
- Definition of Ready.
- Impediment Management.
- Scrum Master Responsibilities.
- Product Backlog Refinement.
- Story Splitting.
- Sprint Review.
- Acceptance Criteria.
- Asynchronous Daily Stand-up.
- Distributed Team Communication.

## Conclusion

This assignment demonstrates how a Scrum team manages external dependencies, maintains sprint commitments, handles impediments and continues delivering business value despite unexpected technical challenges.
